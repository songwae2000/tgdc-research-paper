# What a domain prior can and cannot replace

Short research paper for the TGDC case study, research track. `main.tex` is the
source and compiles to four pages with pdflatex. `main.pdf` is built from the
`main.tex` beside it.

The experiment, data pipeline and pre-registration history live in
https://github.com/songwae2000/real-vs-generated. Every figure in the paper is
printed by `python run_all.py` there. `main.tex` is generated from that
repository's `paper/paper.md`, so the typeset version cannot drift from the text
the figures were checked against.
